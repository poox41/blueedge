# AI Chat History

这个目录用于记录本项目中与 AI 协作的聊天记录和工作摘要。

## 文件命名规则

新开一次窗口或一次相对独立的协作，就新建一个 Markdown 文件：

```text
YYYY年MM月DD日-本次聊天主要内容.md
```

示例：

```text
2026年06月10日-BlueEdge磁盘恢复镜像发布与删除Pod功能.md
```

## 记录内容建议

- 本次目标
- 关键问题和原因
- 实际修改的文件
- 执行过的重要命令
- 发布的镜像 tag
- 验证结果
- 后续注意事项

## 使用说明

AI 不能在后台自动监听所有新窗口的完整聊天原文。实际使用时，可以在每次协作结束前让 AI 按这个目录规则生成或补充记录。
